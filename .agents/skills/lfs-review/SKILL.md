# $lfs-review — ревью задачи без правок

То же, что `/lfs-review` у Claude Code. Процедура у агентов одна: файл `.claude/skills/lfs-review/SKILL.md` от корня
репозитория. Прочитай его целиком и выполни буквально.

- **Аргумент** — LFS-ID после `$lfs-review`. Подставь его вместо `$ARGUMENTS`.
- **Блок YAML в начале того файла** — настройки Claude Code, пропусти его. Строка `allowed-tools` в нём означает то же,
  что и для тебя: файлы не меняешь, запускаешь только чтение git (`status`, `diff`, `log`, `show`, `ls-files`) и читаешь
  файлы.
- **Скриншоты и макеты** открывай своим средством просмотра изображений.
