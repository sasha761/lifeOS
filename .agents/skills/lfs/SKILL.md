# $lfs — задача LifeOS с подтверждением владельца

То же, что `/lfs` у Claude Code. Процедура у агентов одна: файл `.claude/skills/lfs/SKILL.md` от корня репозитория.
Прочитай его целиком и выполни все шаги буквально.

- **Аргументы** — текст после `$lfs` в сообщении владельца: подставь его вместо `$ARGUMENTS`. Текста нет — аргументов
  нет: процедура сама найдёт следующую задачу и остановится, чтобы владелец её подтвердил.
- **Блок YAML в начале того файла** (`description`, `argument-hint`, `disable-model-invocation`) — настройки Claude
  Code. Пропусти его.
- **Картинки-референсы.** Где процедура говорит открыть картинку инструментом Read, открой PNG своим средством просмотра
  изображений.
- **Остановки обязательны:** подтверждение задачи (если ID не указан) и «ОК» владельца на план до первой правки файлов
  (AGENTS.md, п. 3). Режим без остановок — отдельная команда `$lfs-auto`.
