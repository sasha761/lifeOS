# LFS-227 — Каталог онбординга v2

**Этап:** 2 — LifeOS Core (вставка после LFS-226, перед Stage 3, по замечаниям владельца 2026-11-21,
[STAGE-02-FEEDBACK](STAGE-02-FEEDBACK.md), п. 1.1–1.7, 1.9)
**Зависимости:** LFS-219, LFS-222, LFS-225, LFS-226; [ADR-012](../adr/012-onboarding.md); макеты LFS-223
**Цель:** мастер спрашивает числа только там, где без них цель теряет смысл. Остальные варианты становятся целями без
измерений с коротким текстом. «Свой вариант» — одно текстовое поле.

## Почему

В каталоге v1 ([onboarding-catalog.ts](../../packages/domain/src/core/onboarding-catalog.ts)) каждый вариант — числовая цель: «сколько откликов», «сколько модулей»,
«этапов всего», а «Свой вариант» требует направление, единицу, старт и цель. Владелец назвал это топорным: новому
пользователю приходится придумывать цифры.

## Задание

Каталог версии 2. По ADR-012 черновик версии 1 не предлагается, мастер начинается заново.

- [ ] **Финансы** — можно отметить несколько вариантов, до 3, как в Здоровье (лимит подтверждается на макете). У
  каждого отмеченного варианта свой блок уточнений и своя валюта (NOK / USD).

  | Вариант | Поля | Цель |
  |---|---|---|
  | Создать подушку безопасности | сколько нужно; сколько уже есть (0); срок | взносы, «увеличить» |
  | Накопить на крупную покупку | на что (необязательно); сколько нужно; сколько уже есть (0); срок | взносы, «увеличить» |
  | Закрыть долг или кредит | **сумма долга**; срок. Цель = 0 без поля | взносы, «уменьшить» |
  | Начать инвестировать | сколько вложить; сколько уже вложено (0); срок | взносы, «увеличить» |
  | Тратить меньше в месяц | сколько тратите; сколько хотите тратить; срок | текущее значение, «уменьшить» |
  | Свой вариант | текст | без измерений |

- [ ] **Работа** — все варианты становятся целями без измерений. Тексты уточнений сохраняются в описании цели.

  | Вариант | Поля | Название цели |
  |---|---|---|
  | Найти новую работу | в какой сфере ищете работу (необязательно); срок | «Найти новую работу» |
  | Пройти курс или сертификат | чему хотите научиться; дата начала; дата окончания | «Пройти курс: <чему>» или «Пройти курс или сертификат» |
  | Прочитать книги по профессии | какие книги хотите прочитать (многострочное, необязательно); срок | «Прочитать книги по профессии» |
  | Практика технологии | какая технология; срок | «Практика <технология>» |

- [ ] **Проекты** — во всех вариантах только «Название проекта», цель без измерений. Этапы, срок и остальное
  настраиваются позже на странице проекта (этап 9). Вариант «Вести регулярно» без чисел теряет смысл. Убрать его
  или оставить целью без измерений «Вести <проект> регулярно» — решается при одобрении макета.
- [ ] **Навыки** — шахматы, программирование, инструмент, рисование становятся целями без измерений. Необязательное
  поле «Что именно хотите освоить» идёт в описание, срок необязателен.
- [ ] **Языки и Здоровье** — без изменений, кроме «Своего варианта».
- [ ] **«Свой вариант» во всех сферах** — одно текстовое поле до 120 символов. Текст становится названием цели без
  измерений. Направления, единицы, «Частых единиц», чисел и срока нет. Подсказка под полем: позже ассистент
  предложит сделать цель измеримой (этап 7).
- [ ] Панель «Что получится» и итог показывают вид цели: «Отметка «Достигнута»», «Платежи уменьшают долг»,
  «Пополнения увеличивают накопления», формулу текущего значения.
- [ ] Сервер по-прежнему заново строит цели из ответов и создаёт отмеченные одной транзакцией (ADR-012). Вид цели,
  режим подсчёта и даты берутся из шаблона.
- [ ] «+ Добавить цель в другой сфере» на итоге пока работает как сейчас, его переводит на мастер LFS-228.

## Acceptance criteria

- [ ] Unit: сборка каждой цели каталога v2, несколько вариантов Финансов, долг с целью 0, «Свой вариант» без чисел,
  черновик v1 не предлагается.
- [ ] Integration: завершение мастера создаёт цели нужных видов и режимов одной транзакцией, повтор с тем же ключом.
- [ ] e2e: Финансы с двумя вариантами, Работа без чисел, Проект только с названием, «Свой вариант», итог.
- [ ] `pnpm verify`, `pnpm test:ui` зелёные; `pnpm ui:shots` и таблица отличий против макетов LFS-223.
