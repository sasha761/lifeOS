# LFS-102 — Зафиксировать версии стека и ADR

**Зависимости:** LFS-101  
**Цель:** устранить несовместимость рантайма и зависимостей до разработки, получить воспроизводимый `pnpm-lock.yaml`.

## Задание Codex

1. Проверь текущие официальные stable-релизы и требования совместимости **на дату выполнения**: Node.js LTS, pnpm, Turborepo, Next.js/React, TypeScript, Tailwind, shadcn/ui, PostgreSQL, Drizzle/Drizzle Kit, pg-boss, Zod, Vitest, Playwright, Better Auth, grammY, AI SDK и `ts-fsrs`.
2. Прямо укажи в ADR, что **Better Auth, grammY, AI SDK и ts-fsrs будут реализованы позже**: в Этапе 1 нам нужны совместимость и решение о версиях, но не настройка фич.
3. Зафиксируй Node `engines` и `.nvmrc` или `.node-version`; в README дай путь для Windows 11/PowerShell и WSL2/Linux. Учти, что требования `ts-fsrs` могут быть строже Next.js. Если несовместимы — выбери совместимый набор и запиши trade-off, не игнорируй.
4. Закрепи точные версии основных реально установленных пакетов, создай `pnpm-lock.yaml` и поле `packageManager`. Не используй непроверенные prerelease/beta без явного ADR.
5. Создай `docs/adr/001-stack.md` с таблицей `Компонент | Версия | Зачем | Где используется | Источник/дата проверки` и ссылками на официальные docs. Отдельно ADR: `pg-boss` вместо Redis, один Next.js app и отдельный worker.
6. Проверь, что `pnpm install --frozen-lockfile` воспроизводим на выбранной среде. Если сеть недоступна — не выдавай условный результат за успешную установку.

## Acceptance criteria

- [ ] Совместимость по Node/pnpm/Next/pg-boss/Drizzle задокументирована; известны ограничения будущего `ts-fsrs`.
- [ ] Есть ADR с причинами, версией и датой проверки каждой критичной зависимости.
- [ ] `pnpm-lock.yaml` в репозитории; установка в frozen-lockfile режиме проходит, если сеть доступна.
- [ ] Реальные зависимости используют pinned resolved versions; нет молчаливого обновления пакетов других задач.
- [ ] Не внедрены auth, Telegram, AI, FSRS.

## Проверки

`node --version`; `pnpm --version`; `pnpm install --frozen-lockfile`; `pnpm -r list --depth 0`; `git diff --check`.

## Вне scope

Не делать UI, БД, worker и реальную регистрацию; не создавать неиспользуемые сервисы «на будущее».

## Definition of Done

Один согласованный стек, подтверждённая совместимость, lockfile и архитектурное решение `ADR-001`.
