# LFS-103 — Next.js Web Shell и дизайн-система

**Зависимости:** LFS-102  
**Цель:** запустить минимальный UI LifeOS на Next.js/React и подготовить разделение Web и Mini App, не реализуя бизнес-функции.

## Задание Codex

1. В `apps/web` настрой **Next.js App Router**, React, TypeScript strict, Tailwind и shadcn/ui по версиям ADR. Используй общее ESLint/TS config из `packages/config`, где возможно.
2. Определи один общий `app/layout.tsx`; route groups `(web)` и `(telegram)` для раздельных UX layouts. **В URL обязательно явный сегмент `/telegram`**: `app/(telegram)/telegram/page.tsx`, поскольку `(telegram)` не входит в URL.
3. Создай `/` с понятным заголовком LifeOS и навигацией по будущим шести сферам. У сфер только подписи/пустые состояния — **без демоданных, выдуманных процентов, поддельных финансов**.
4. Добавь `/telegram` как минимальную безопасную заглушку Mini App, показывающую «Telegram Mini App появится позже». **Не** эмулируй Telegram-авторизацию.
5. Создай базовые дизайн-токены (цвета, типографика, spacing, focus) и универсальные UI-компоненты: layout, navigation, empty state, loading, error boundary/404 (по необходимости). Интерфейс мобильный и доступный с клавиатуры.
6. Подключи `GET /api/health`, возвращающий JSON `status: ok`, service и timestamp, **без проверки БД**, которой ещё может не быть.
7. Реализуй скрипты `dev`, `build`, `lint`, `typecheck`. Не добавляй вызовы AI или защищённые пользовательские маршруты в этой задаче.

## Acceptance criteria

- [ ] `pnpm dev` запускает Web, `/` открывается, `/telegram` доступен.
- [ ] Разделы Languages/Finance/Work/Projects/Skills/Health представлены как **будущие** модули; никаких фиктивных метрик.
- [ ] Route groups не создают конфликтов URL и не требуют Telegram SDK.
- [ ] UI читаем на узком экране и доступен клавиатурой, есть пустые состояния.
- [ ] `GET /api/health` возвращает 200 и не раскрывает секреты.

## Проверки

`pnpm lint`; `pnpm typecheck`; `pnpm build`; ручное открытие `/`, `/telegram`, `/api/health`; при возможности скриншот на мобильном viewport. Приведи реальные результаты.

## Вне scope

Better Auth, реальные Dashboard данные, цели, Mini App SDK, таблицы БД, Telegram webhook.
