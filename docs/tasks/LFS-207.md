## Задание Codex
- [x] Оформи endpoints: `GET/POST /api/v1/goals`, `GET/PATCH /api/v1/goals/:goalId`, `GET/POST /api/v1/goals/:goalId/measurements`, `PATCH/DELETE /api/v1/goal-measurements/:measurementId`; архивирование цели через PATCH status, без hard delete в Stage 2.
- [x] Применяй утверждённый response envelope `data/meta/errors`, 401 для гостя, 404 для чужого/несуществующего ресурса, 400/422 для валидации, 409 для конфликтов; не раскрывай существование чужого ID.
- [x] Расчёт: increase `(current-baseline)/(target-baseline)`; decrease `(baseline-current)/(baseline-target)`; UI процент clamp 0..100, исходное значение current хранить без изменений.
- [x] Без измерений возвращай `current:null, progressPercent:null` с объяснением «Недостаточно данных»; не превращай отсутствие данных в 0%. Обработай baseline==target отдельно и цели за пределами target.
- [x] Отдавай `methodology`, `source/provenance`, `unit`, `baseline`, `target`, `current`, `updatedAt`, `measurement count` в contract; суммы NOK обрабатывать точно.
- [x] На write endpoints выполняй ownership на уровне сервиса/репозитория, audit transaction и Idempotency-Key для повторяемых операций; задокументируй семантику ключей.
- [x] Добавь cursor/limit пагинацию для истории (в пределах разумного размера), ISO timestamps + timezone-aware представление в UI.

### Acceptance evidence

- [x] 12000/50000 = 24%, долг 100000→0 при 80000 = 20%; exact adjacent
  NOK выше MAX_SAFE_INTEGER и на верхней decimal границе; 10^-8 единицы,
  half-up, under/over target. Current не округляется и не clamp-ится.
- [x] No measurement → current/progressPercent null + «Недостаточно данных»;
  измеренный 0 → реальные 0%. Equal/reversed definition обрабатывается
  calculator без деления на ноль, создание такой цели — безопасный 400.
- [x] Все восемь endpoints: 401 для гостя/forged cookie до input parsing,
  reusable two-user contract 404 для чужого и неизвестного id; own reads/
  writes успешны. List другого пользователя не содержит цели владельца.
- [x] Goal/measurement POST, PATCH metadata, PATCH archive и DELETE replay:
  по одному эффекту/event/receipt, changed input/shared-key conflict → 409;
  replay удалённого measurement create → 404 без resurrection.
- [x] Ошибки unit/decimal/owner/definition/future date, malformed JSON,
  content-type, missing/bad key, смешанное архивирование и query → 400,
  без записей. Receipt AFTER INSERT failure → safe 500 и полный rollback
  goal/measurement/edit/delete, тот же key повторяем после устранения сбоя.
- [x] History из 105 записей читается 100+5; равные timestamps и UUID tie,
  seek по measured_at/created_at, удалённый cursor row, no duplicate на
  неизменном наборе; goal filters и filter/goal cursor mismatch проверены.
- [x] Read snapshot при concurrent commit: текущий ответ сохраняет старые
  current/count, новый read видит оба новых значения. No-data цели не
  исчезают из списка; count считает все существующие измерения.
- [x] Methodology/provenance/unit/exact values/count/updatedAt выходят через
  строгий DTO; note отсутствует в progress. Логи содержат только allowlisted
  technical fields, не owner/token/password/note/SQL.
- [x] ISO UTC/offset сохраняются; существующий timezone-aware formatter
  проверен через DST Europe/Oslo и fallback UTC. Нового UI не добавлено
  согласно разделу «Вне scope», его подключение — LFS-208.
