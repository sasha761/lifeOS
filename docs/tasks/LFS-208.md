### Поведение

Без замеров показаны «Недостаточно данных» и целевое значение; progress bar
не создаётся. С замерами — exact current/target и серверный процент, ручной
источник/самоотчёт/дата. Клиент не пересчитывает проценты. После каждой
мутации detail и history перечитываются. Archive явно закрывает изменения,
история остаётся видимой. Фильтры и следующие страницы доступны в списке,
history использует API cursor. Custom unit и уменьшение значения поддержаны
тем же контрактом, определение цели не редактируется задним числом.

Text decimal fields нормализуют запятую в точку, не используют Number для
значений. Intl группирует BigInt integer, дробная часть остаётся строкой.
Datetime-local относится к account timezone, сохраняет миллисекунды;
несуществующий DST момент отклоняется, неоднозначный требует UTC offset.

Синхронный submit lock, disabled fields и отдельная блокировка на время
navigation защищают от двойной записи. После network/500/невалидного ответа
сохраняются body/key в памяти формы; повтор отправляет их без изменений.
Definitive validation/conflict позволяет правку с новым key. Payload/key не
пишутся в browser storage/logs. Неподтверждённую попытку следует повторять в
той же форме: перезагрузка вкладки сбрасывает её локальное состояние.
