# LFS-224 — Карточка цели: клик по всей карточке, hover, удаление

**Этап:** 2 — LifeOS Core (вставка после LFS-223, перед Stage 3, по замечаниям владельца 2026-11-21,
[STAGE-02-FEEDBACK](STAGE-02-FEEDBACK.md), п. 2.1–2.2)
**Зависимости:** LFS-208, LFS-213, LFS-216; макеты `32-goals-list`, `36-goals-list-no-measure`, `44-mobile-goals` (LFS-223)
**Цель:** список целей в новом виде (макет 32): строка цели выбирается кликом по любой её части, у строки есть hover,
кнопку «+ Первое измерение» заменяет иконка «Удалить», панель цели облегчена.

## Почему

Сейчас ссылка — только название цели ([goals-browser.tsx](../../apps/web/components/goals/goals-browser.tsx), `GoalRow`), а промах мимо названия ничего не делает.
«+ Первое измерение» дублирует кнопку «+ Измерение» в панели, а удалить цель из списка нельзя: удаление спрятано в
меню «⋯» панели (LFS-216).

## Область изменений

- `apps/web/components/goals/goals-browser.tsx` (`GoalRow`), при необходимости `components/ui/card.tsx`
- Диалог подтверждения удаления из `goal-detail.tsx` — переиспользовать, не копировать
- Тесты `apps/web/tests/`, e2e, `scripts/ui-shots.ts`

  Внутри ссылки нет других интерактивных элементов: используется растянутая ссылка или похожий приём, кнопка
  удаления остаётся отдельной кнопкой.

  LFS-225.

  - «Удалить» — отдельная кнопка поверх ссылки, `aria-label` «Удалить цель «…»». С мышью от 1024 px она появляется
    при наведении и при фокусе внутри строки, на сенсорных экранах и уже 1024 px видна всегда, 40 px;

    выбранная строка как раньше. Первая цель, выбранная по умолчанию, подсвечивается только от 1024 px: на телефоне
    её панели рядом нет (макет 44).
- **Удаление с карточки**: подтверждение вынесено из панели в `DeleteGoalDialog` (`goal-detail.tsx`), его открывают
  и «⋯ → Удалить цель», и кнопка на строке. После удаления список и счётчики перечитываются, открытая удалённая цель
  уступает первой цели списка (как раньше), фокус переходит на ссылку следующей строки, затем предыдущей, иначе на
  список. Отмена возвращает фокус на кнопку «Удалить».
- **Панель цели** (`GoalPanel`, макет 32):
  - шапка: чип статуса рядом с названием, под ним «сфера · увеличить ↑ · до …» вместо чипов;
