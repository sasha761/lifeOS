# LFS-224 — Карточка цели: клик по всей карточке, hover, удаление

**Этап:** 2 — LifeOS Core (вставка после LFS-223, перед Stage 3, по замечаниям владельца 2026-11-21,
[STAGE-02-FEEDBACK](STAGE-02-FEEDBACK.md), п. 2.1–2.2)
**Зависимости:** LFS-208, LFS-213, LFS-216; макеты `32-goals-list`, `36-goals-list-no-measure`, `44-mobile-goals` (LFS-223)
**Цель:** список целей в новом виде (макет 32): строка цели выбирается кликом по любой её части, у строки есть hover,
кнопку «+ Первое измерение» заменяет иконка «Удалить», панель цели облегчена.

## Почему

Сейчас ссылка — только название цели ([goals-browser.tsx](../../apps/web/components/goals/goals-browser.tsx), `GoalRow`), а промах мимо названия ничего не делает.
«+ Первое измерение» дублирует кнопку «+ Измерение» в панели, а удалить цель из списка нельзя: удаление спрятано в
меню «⋯» панели (LFS-216).

## Область изменений

- `apps/web/components/goals/goals-browser.tsx` (`GoalRow`), при необходимости `components/ui/card.tsx`
- Диалог подтверждения удаления из `goal-detail.tsx` — переиспользовать, не копировать
- Тесты `apps/web/tests/`, e2e, `scripts/ui-shots.ts`

## Задание

- [ ] Строка цели — по макету 32: квадрат сферы, название, «сфера · срок»; справа полоса и процент с коротким итогом,
  у числовой цели без измерений — «Нет данных · добавьте первое измерение». Подписи источника на строке нет, она в
  панели. Вид «Доска» и переключатель — LFS-229; до неё `/goals` показывает список.
- [ ] Клик по любой части карточки открывает цель (`/goals/[id]` с текущими фильтрами), как сейчас ссылка-название.
  Внутри ссылки нет других интерактивных элементов: используется растянутая ссылка или похожий приём, кнопка
  удаления остаётся отдельной кнопкой.
- [ ] Hover и `focus-visible` строки — по макетам 32 и 33, только токенами. Выбранная строка выглядит как сейчас.
- [ ] «+ Первое измерение» убрана. На строке (активной и архивной) — иконка «Удалить» с `aria-label`
  «Удалить цель «…»». На десктопе она появляется при наведении и при фокусе внутри строки, на телефоне видна всегда
  (решение владельца, LFS-223). Она открывает то же подтверждение, что «⋯ → Удалить» в панели. После удаления всё как сейчас:
  список и счётчики перечитываются, выбор переходит на следующую цель, фокус возвращается в список.
- [ ] Клавиатура: Tab проходит по ссылке цели и кнопке «Удалить», Enter открывает цель, на кнопке удаления — диалог.
- [ ] 390 px: иконка видна без hover, зона нажатия не меньше 40 px.
- [ ] Панель цели — облегчённая, по макету 32: строка «сфера · вид · срок» вместо чипов, крупный процент и полоса,
  «Осталось · N дней до срока», одна главная кнопка добавления измерения, список измерений, внизу «Как считается ›»
  и «История изменений · N ›» — раскрывающиеся разделы панели (формула и журнал уходят в них). Плиток
  «Старт / Сейчас / Цель / Осталось» нет. Тексты кнопок и списка по виду цели меняет LFS-226, вид без измерений —
  LFS-225.

## Acceptance criteria

- [ ] Unit: карточка — одна ссылка и одна кнопка, без вложенных интерактивных элементов.
- [ ] e2e: клик по пустой области карточки открывает цель; удаление с карточки с подтверждением и отменой; фокус после
  удаления.
- [ ] `pnpm verify`, `pnpm test:ui` зелёные; `pnpm ui:shots` 1440/390 и таблица отличий против макетов 32 и 44 (список).

Карточки на Dashboard и странице сферы (другие компоненты), массовое удаление, отмена удаления. Доска и переключатель
вида — LFS-229.
