## Продукт и рамки

LifeOS — мультидоменная платформа с шестью сферами: Languages, Finance, Work, Projects, Skills, Health. Этап 2 делает общую инфраструктуру аккаунтов, целей, ручных измерений и Dashboard. Это **не** отдельное приложение для языков. Специализированные модули (Telegram/AI Tutor/FSRS/финансы/доски задач) — в следующих этапах.

## Обязательное правило выполнения

Одна Codex-сессия — одна `LFS-XXX.md`. Не заставляй Codex исполнять всё сразу. Перед каждой задачей он изучает `AGENTS.md`, Master Plan, текущие миграции/ADR и фактический код. Если задача уже частично сделана, Codex должен дорабатывать, а не дублировать.

Структура этого ZIP содержит **только новые файлы `docs/tasks`**, чтобы не перезаписать Stage 1 `AGENTS.md` и README.

## Exit criteria этапа

1. Вход, выход и закрытая регистрация действительно работают.
2. Есть шесть сфер без фиктивного прогресса.
3. В любой сфере можно создать ручную цель и зафиксировать числовое значение.
4. Рост/уменьшение и отсутствие данных считаются корректно; источник показан.
5. Изменение/удаление измерения обновляет Dashboard, оставляя audit.
6. Два пользователя не могут просматривать/изменять чужие данные.
7. Повторные операции не дают дубликатов, миграции и CI проверены.
8. Stage 1 PostgreSQL/worker/health остаются рабочими.

Полная проверка — `STAGE-02-ACCEPTANCE.md`.
