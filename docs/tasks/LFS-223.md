# LFS-223 — Макеты доработок Stage 2

**Этап:** 2 — LifeOS Core (вставка после LFS-222, перед Stage 3, по замечаниям владельца 2026-11-21,
[STAGE-02-FEEDBACK](STAGE-02-FEEDBACK.md))
**Зависимости:** решения владельца в STAGE-02-FEEDBACK; [UI_GUIDELINES](../UI_GUIDELINES.md), макеты `09`, `10`, `25`–`27`, `29`
**Цель:** до кода нарисовать экраны, которые меняют LFS-224–228, и получить одобрение владельца. Кода приложения в
задаче нет.

## Почему

UI делается строго по макетам. Замечания меняют карточку цели, мастер и диалог новой цели настолько, что прежние
макеты 09, 10 и 25–27 перестают быть целевым видом. Владелец решил (2026-11-22, решение 7): для изменённых экранов
делаются новые макеты.

## Решения владельца · 2026-11-22

См. [STAGE-02-FEEDBACK](STAGE-02-FEEDBACK.md#решения-владельца--2026-11-22), все восемь пунктов: макеты их показывают.

## Формат

- Как у существующих: `docs/reference/ui/html/NN-name.html` (точные размеры, тот же CSS и палитра, что в `25-onb-question.html` и
  `09-goals.html`) и снимок `docs/reference/ui/NN-name.png`. Номера — с 32. Один файл может показывать несколько
  состояний рядом, как `26-onb-own-answer`.
- PNG снимается из HTML (Playwright уже есть в проекте) на 1440. Для мобильного — отдельный файл на 390.
- Данные на макете примерные и в код не переносятся (README макетов).
- Только существующие компоненты Design System v2: карточка, pill, `SegmentedTabs`, чип статуса, полоса прогресса,
  диалог. Новый компонент допустим, если без него никак, и тогда он описан в отчёте.

## Задание

Нужны состояния (разбивку по файлам выбирает исполнитель):

- [ ] **`/goals`, список** (LFS-224–226), основа — `09-goals`:
  - карточка в обычном виде, при hover и выбранная; иконка «Удалить» на месте «+ Первое измерение»;
  - три вида целей в списке: цель-состояние (вес: «сейчас 85 кг · цель 80 кг»), накопительная («Выплачено 800 из 2 000 $ ·
    осталось 1 200 $», «Накоплено 3 000 из 10 000 NOK»), цель без измерений (чип «В процессе» / «Достигнута», даты
    начала и окончания, без полосы прогресса).
- [ ] **Правая панель цели** (LFS-225, LFS-226):
  - цель без измерений: описание, даты начала и окончания, «Отметить достигнутой», вид после отметки с
    «Вернуть в работу», история;
  - накопительная цель: выплачено или накоплено, остаток, процент, список взносов «Платёж 800 $».
- [ ] **Окна измерения** (LFS-226): «Внести платёж» (долг), «Пополнить» (накопления, инвестиции), «Новое значение»
  (вес, расходы за месяц), исправление взноса.
- [ ] **Мастер, вопросы v2** (LFS-227), основа — `25`, `26`:
  - Финансы: несколько вариантов отмечены, у каждого свой блок уточнений; долг — одно поле «Сумма долга» и валюта;
  - Работа: «Найти новую работу» (необязательное «В какой сфере ищете работу»), курс («Чему хотите научиться»,
    дата начала, дата окончания), книги («Какие книги хотите прочитать», срок), практика технологии («Какая
    технология»);
  - Проекты: только «Название проекта»;
  - Навыки: варианты без чисел, необязательное «Что именно хотите освоить»;
  - «Свой вариант»: только текстовое поле;
  - шкала шагов без «Ритма»; панель «Что получится» для цели без измерений и для накопительной цели.
- [ ] **Итог мастера** (LFS-227), основа — `27`: список целей разных видов, без ритма.
- [ ] **`/goals/new`, мастер в диалоге** (LFS-228), основа — `10` и `25`: сфера → вопрос сферы с вариантами и
  «Свой вариант» → уточнения → предпросмотр и «Создать цель» (для Финансов — «Создать N целей»). Вид при открытии со
  страницы сферы (первый шаг пропущен).
- [ ] **390 px**: карточка цели со значком удаления, шаг мастера новой цели, вопрос онбординга с несколькими вариантами.
- [ ] Показать владельцу PNG и получить «ОК» до коммита. Правки по его замечаниям — в той же задаче.
- [ ] Обновить `docs/reference/ui/README.md` (новые файлы), `PAGES.md` (какой макет к какой странице, старые 09, 10,
  25–27 помечены «заменён NN для …»), `ONBOARDING.md` (ссылки на новые макеты).

## Acceptance criteria

- [ ] Каждое состояние из списка есть хотя бы на одном макете; HTML открывается в браузере без внешних зависимостей,
  кроме шрифта.
- [ ] Цвета, радиусы и размеры совпадают с прежними макетами (одна палитра, тот же `.wrap` 1180).
- [ ] Владелец одобрил макеты; это записано в «Решения владельца» этого файла с датой.

## Вне scope

Код приложения. Макеты модулей Проекты, Финансы и Поиск работы (пожелания — в STAGE-02-FEEDBACK). Настройки без
блока ритма: блок просто исчезает, макет не нужен.
