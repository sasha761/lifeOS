# LFS-222 — Удалить ритм отметок

**Этап:** 2 — LifeOS Core (вставка после LFS-221, перед Stage 3, по замечаниям владельца 2026-11-21,
[STAGE-02-FEEDBACK](STAGE-02-FEEDBACK.md))
**Зависимости:** LFS-219, LFS-220; [ADR-012](../adr/012-onboarding.md)
**Цель:** ритм отметок убран из продукта целиком: шаг мастера, Настройки, API и колонка БД. Часовой пояс меняется
только в Настройках.

## Почему

Ритм ничего не меняет: напоминаний нет до Stage 3, а лишний шаг удлиняет мастер. Кроме того, шаг «Ритм» —
единственное место мастера, где подтверждается часовой пояс, хотя тот же выбор уже есть в Настройках («Язык и время»).

## Решения владельца · 2026-11-22

1. Ритм удаляется полностью: шаг мастера, блок в Настройках, поле в API и колонка `checkin_rhythm` вместе с
   сохранёнными значениями.
2. Часовой пояс уходит из мастера, его меняют в Настройках.

## Область изменений

- `packages/contracts/src/onboarding.ts`: `checkinRhythmSchema`, `rhythm` и `timezone` в черновике, `checkin_rhythm` в
  `OnboardingState`, вариант `PATCH { checkin_rhythm }`
- `packages/domain/src/core/onboarding-catalog.ts` (`CHECKIN_RHYTHM_OPTIONS`, пустой черновик), `core/onboarding.ts`
  (завершение больше не пишет ритм и пояс)
- `packages/db`: `schema/auth.ts`, `repositories/onboarding.ts`, новая миграция, удаляющая колонку
- `apps/web`: `components/onboarding/{onboarding-wizard,steps,summary-step}.tsx`, `components/settings/onboarding-section.tsx`,
  `lib/onboarding-presentation.ts`, `server/onboarding.ts`, `scripts/ui-shots.ts`
- Тесты, где встречается ритм: contracts, domain, integration `onboarding.test.ts`, `migrations.test.ts`, e2e
  `start-dialog.spec.ts`, `onboarding-presentation.test.ts`
- Документы: ADR-012 (дополнение), `database-schema.md`, `docs/api/contracts.md`, `ONBOARDING.md`, `system.md` и
  `README.md`, если там упомянут ритм

## Задание

- [ ] Мастер: шагов «Ритм» нет. После вопроса последней выбранной сферы идёт «Итог», шкала и «Шаг N из M»
  пересчитаны. Если сфер не выбрано, мастер устроен как сейчас, только без «Ритма».
- [ ] Итог и панель «Что получится» не упоминают ритм и напоминания.
- [ ] Сохранённый черновик открывается без ошибки, даже если в нём есть `rhythm`, `timezone` или текущий шаг —
  «Ритм». Лишние значения отбрасываются, мастер открывается на «Итоге». Версия каталога не меняется.
- [ ] `POST /api/v1/onboarding/complete` больше не меняет часовой пояс профиля и ритм.
- [ ] `PATCH /api/v1/onboarding` принимает только выборы попапа; тело с `checkin_rhythm` получает 400.
  `OnboardingState` без `checkin_rhythm`.
- [ ] Настройки → «Начальная настройка»: строки «Ритм отметок» нет. Часовой пояс по-прежнему меняется в «Язык и время».
- [ ] Новая миграция удаляет колонку `user.checkin_rhythm`. Применённые миграции не переписываются.
- [ ] В дополнении к ADR-012 записать, что ритм удалён, пояс меняется только в Настройках, и как откатиться:
  код LFS-221 читает колонку, поэтому откат кода требует миграции, которая вернёт колонку.

## Acceptance criteria

- [ ] Тесты контракта: черновик со старыми ключами читается, `PATCH` с `checkin_rhythm` отклоняется.
- [ ] Integration: завершение мастера не трогает пояс профиля; миграция на чистой схеме и обновление с `0008`.
- [ ] e2e: мастер без шага «Ритм» на 1280 и 390, Настройки без блока ритма.
- [ ] `pnpm verify`, `pnpm test:ui`, `pnpm build` и `pnpm test:build` зелёные. Снимки `pnpm ui:shots` и таблица
  отличий: шаги без «Ритма» и Настройки без блока отличаются от макетов 24–27, 29, 30 по решению владельца.

## Вне scope

Напоминания (Stage 3). Определение часового пояса по браузеру при регистрации. Риск: новый пользователь остаётся в
UTC, пока сам не сменит пояс в Настройках, поэтому срок цели может закончиться в другое время суток. Если это нужно
исправить, это отдельная задача.
