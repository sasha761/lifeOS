# Stage 2 — Acceptance Checklist

> Заполняется Codex при выполнении `LFS-209`. Ставит галочки **только** после проверок; для каждого пункта прикладывает команду/тест или наблюдаемый результат.

## Функции

- [ ] Allowed email может зарегистрироваться; email вне allowlist не может; существующие пользователи входят и выходят.
- [ ] Пользователь может сбросить пароль через реально настроенный dev email transport; механика продакшн-доставки документирована.
- [ ] Неавторизованные запросы к целям возвращают 401; UI защищён.
- [ ] Всего 6 сфер (`languages`, `finance`, `work`, `projects`, `skills`, `health`), нет ложных показателей.
- [ ] В любой сфере создаётся ручная цель; `computed` до интеграции metric provider недоступен.
- [ ] При отсутствии измерения Dashboard показывает «Недостаточно данных», а не вымышленный 0%.
- [ ] Finance: baseline 0, target 50000 NOK, current 12000 ⇒ 24%.
- [ ] Decrease: долг baseline 100000, target 0, current 80000 ⇒ 20%.
- [ ] При current > target UI показывает 100% (clamp), но actual current не теряется.
- [ ] baseline == target обработан без division by zero и объяснён методологически.
- [ ] Добавить/изменить/удалить измерение можно через UI, Dashboard актуализируется.
- [ ] `measured_at` определяет порядок; backdated ввод не искажает текущую величину.
- [ ] Audit events пишутся вместе с доменной операцией в транзакции, rollback проверен.
- [ ] Идемпотентность повторного POST/других retry-safe операций подтверждена тестами.

## Security / качество

- [ ] Есть тесты минимум на двух пользователей для чужих goals/measurements/events.
- [ ] Body `userId` не может подменить серверный actor.
- [ ] Известные ошибки валидации и конфликтов используют общий API envelope.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` (или задокументированные скрипты) завершены успешно; отказ не замаскирован.
- [ ] Миграции применяются к чистой БД и upgrade существующей Stage 1 базы не стирает данные.
- [ ] Worker/pg-boss и `/api/health` продолжают работать.
- [ ] UI проверен на мобильном экране и с клавиатурой.
- [ ] Реальных Telegram/AI/банковских подключений в этом этапе нет.
