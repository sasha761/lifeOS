# LFS-211 — Design System v2: тёмная тема, Inter, новая оболочка

**Этап:** 2 — LifeOS Core (вставка в очередь **перед LFS-204**)  
**Зависимости:** LFS-103, LFS-208; [ADR-011](../adr/011-design-system-v2.md)  
**Референс:** [спека §16](../reference/LifeOS_Design_Tasks_Jobs_v0.2.md), [макеты](../reference/ui/README.md) — прежде всего `01-main.png` и общая шапка на остальных снимках.  
**Цель:** Перевести существующий Web UI на новую визуальную систему без изменения поведения, URL, API и данных.

- `apps/web/app/layout.tsx` — подключение Inter
- `apps/web/app/(web)/layout.tsx`, `components/brand.tsx`, `components/area-navigation.tsx`, `components/navigation-link.tsx` — новая оболочка

- `apps/web/package.json` + `pnpm-lock.yaml` — только если выбран пакет шрифта
- `docs/adr/011-design-system-v2.md` — статус и раздел «Проверка»

## Результат LFS-211 · 2026-11-17

Ветка `lfs-211-design-system`. Существующий Web UI переведён на Design System v2
([ADR-011](../adr/011-design-system-v2.md), статус Accepted): тёмная палитра, Inter, верхняя
полоса вместо левого сайдбара, pill-кнопки и `SegmentedTabs`. API, схема БД, URL и данные
не менялись; новых экранов и компонентов будущих модулей нет, LFS-204 не начата.
