- [ ] Все существующие unit, PostgreSQL integration и Playwright (LFS-208) тесты проходят без ослабления проверок.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm verify`.
- [ ] Скриншоты 1280px и 390px: `/`, `/dashboard`, `/goals`, `/goals/new`, `/settings`, `/auth/sign-in` — приложены в отчёт и визуально соответствуют `01-main.png` (палитра, шрифт, pill-элементы, верхняя полоса).
