## Когда показывается попап

- На `/dashboard` после входа, если у пользователя **нет ни одной цели** (активной или в архиве) и начальная
  настройка не завершена и не отклонена. Условие считается на сервере.
- «✕» закрывает до следующего входа. «Начать с чистого листа» больше попап сам не показывает.
- Если мастер начат и прерван («Сохранить и выйти»), при следующем входе вместо выбора: «Продолжить настройку».
- В ⚙ Настройки → «Начальная настройка» кнопка «Открыть начальную настройку» открывает этот же попап в любой
  момент (`30`, `31`): «Начать вопросы» (новые цели добавляются к существующим, ничего не удаляется) и
  «Добавить пример» (неактивна, пока в аккаунте есть примерные цели). Вместо «Начать с чистого листа» — «Закрыть».

## Вариант 1: пример

- Набор из LFS-218: 7 целей во всех шести сферах и 7 примерных измерений, без сроков.
- Всё помечено чипом «Пример»: у целей `origin = starter`, у измерений `source = example`, источник событий `starter`.
- Примерная цель становится своей (`origin = manual`, чип пропадает) при первой правке или первом собственном
  измерении.
- На Кабинете, пока есть хотя бы одна примерная цель, баннер «Это пример» с двумя кнопками:
  - **«Удалить все примеры»**: подтверждение, затем одной транзакцией удаляются все цели с `origin = starter`
    с их измерениями и историей. Цели, которые пользователь сделал своими, остаются.
  - **«Пройти настройку вместо примера»**: то же удаление после подтверждения, затем мастер.
- Первое собственное измерение цели убирает её примерные измерения (как в LFS-218 + LFS-217).

## Вариант 2: мастер

Шаги: **Сферы → по одному вопросу на каждую выбранную сферу (в порядке реестра) → Итог.**
От 3 экранов (одна сфера) до 8 (все шесть). Шкала шагов сверху строится по выбранным сферам. Шаг «Ритм» с макетов
`23`–`27` и `29` удалён по решению владельца 22.11.2026 (LFS-222); часовой пояс меняется только в Настройках.

Общие правила:
- В каждом вопросе есть готовые варианты и **«Свой вариант»**: свободный текст до 120 символов становится
  названием цели. После выбора открывается блок «Уточните цифры».
- Вариант ответа — это заготовка цели (название, как считать, единица), а цифры вводит пользователь.
  Режимы те же, что в обычной форме цели: «Увеличить до значения» и «Уменьшить до значения».
  Повторяющееся («3 раза в неделю») задаётся единицей, как в LFS-218: «тренировок в неделю», 0 → 3.
- Срок везде необязателен. Любой вопрос можно пропустить. «Назад» не теряет ответы.
- «Сохранить и выйти» сохраняет черновик ответов на сервере.
- **До кнопки «Создать N целей» на итоге ничего не создаётся.** Цели создаются одной транзакцией теми же
  доменными командами и с тем же аудитом, что ручные (источник события `onboarding`).
- **Измерения мастер не создаёт.** «Сколько уже есть» / «Сейчас» становится стартом цели; на карточке
  «Нет данных» до первого измерения. Так в мастере нет ни одной выдуманной цифры (AGENTS.md).
- Справа на десктопе панель «Что получится» обновляется по ходу ответа.

## Что хранится

- `onboarding_state` на пользователя (LFS-219): статус (`not_started`, `in_progress`, `completed`, `dismissed`),
  выбор (`example`, `wizard`, `blank`), черновик ответов, версия каталога вопросов, время завершения.
- В профиле: `focus_domains` (сферы в фокусе показываются первыми в Кабинете). `checkin_rhythm` удалён в LFS-222.
- У целей `origin`: `manual`, `starter` (пример, LFS-218), `onboarding` (мастер, LFS-219).
