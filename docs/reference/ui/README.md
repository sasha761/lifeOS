# UI-макеты LifeOS (Design System v2)

Статические снимки макетов к [спеке дизайна, Tasks и Job Search](../LifeOS_Design_Tasks_Jobs_v0.2.md)
и к [мастер-плану](../LifeOS_Master_Plan_v0.4.md). Полный список страниц проекта и какой макет к какой
странице относится: [PAGES.md](PAGES.md).
Точные размеры, отступы и цвета каждого экрана — в `html/NN-name.html` (тот же макет как HTML: откройте в браузере
или читайте CSS). Как переводить их в Tailwind и как проверять результат — [UI_GUIDELINES](../../UI_GUIDELINES.md).
Исходный редактируемый холст: https://claude.ai/artifact/VXQUjJVeHjmXAAD2zREUnk (приватный, доступ у владельца).

**Важно для Codex и Claude Code:** все числа, компании, слова и задачи на макетах — примерные данные для вида
экрана. Их нельзя переносить в код как значения по умолчанию или демо-данные (см. AGENTS.md: без фиктивных
процентов и показателей). Макеты задают стиль, компоновку и компоненты; данные — только из реальных записей.
Если на макете нет нужного состояния (пусто, ошибка, загрузка), берите компоненты из `01-main.png`.

## Общие правила

- Верхняя полоса без фона: логотип и текущий раздел слева, справа pill-кнопки разделов и настройки.
- Контент по центру, max-width ~1180px.
- Pill-переключатели (`SegmentedTabs`) и pill-кнопки; карточки `rounded-2xl`, тонкие границы.
- Тёмная фиолетовая палитра, Inter, цвет только для смысла (сфера, статус, нагрузка).
- У каждой цифры подпись с источником: «ручной ввод», «измерено системой», «оценено тестом», «самоотчёт», «предположение AI».
- Кнопки разделов показываются **только для существующих модулей**. На макетах MVP это «Обзор, Цели, Сферы, Языки, Ассистент»,
  на макетах после MVP — «Мой прогресс, Задачи, Проекты, Ассистент». Итоговый состав полосы решается, когда появится модуль Tasks
  (см. PAGES.md).
