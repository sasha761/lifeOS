# UI-макеты LifeOS (Design System v2)

Статические снимки макетов к [спеке дизайна, Tasks и Job Search](../LifeOS_Design_Tasks_Jobs_v0.2.md).
Исходный редактируемый холст: https://claude.ai/artifact/VXQUjJVeHjmXAAD2zREUnk (приватный, доступ у владельца).

**Важно для Codex:** все числа, компании и задачи на макетах — примерные данные для вида экрана.
Их нельзя переносить в код как значения по умолчанию или демо-данные (см. AGENTS.md: без фиктивных
процентов и показателей). Макеты задают стиль, компоновку и компоненты; данные — только из реальных записей.

| Файл | Экран | Когда реализуется |
|---|---|---|

Общие элементы на всех экранах, которые вводятся уже в LFS-211:

- верхняя полоса без фона: логотип слева, справа pill-кнопки разделов и настройки;
- контент по центру, max-width ~1180px;
- pill-переключатели (`SegmentedTabs`) и pill-кнопки;
- тёмная фиолетовая палитра, Inter, тонкие границы, цвет только для смысла.

Кнопки разделов показываются **только для существующих разделов**: «Задачи», «Проекты», «Ассистент» появятся
вместе со своими модулями, в LFS-211 их нет.
