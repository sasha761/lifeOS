# Архитектурные решения (ADR)

Журнал принятых решений LifeOS. Подробности — в самих файлах.

## Куда записывать решение

- **Решение меняет архитектуру, стек, модель данных или действует за пределами одной задачи** — ADR. Новый файл
  по [шаблону](000-template.md) со следующим свободным номером и строка в таблице ниже.
- **Решение уточняет уже принятое** — датированное дополнение в конце существующего ADR
  («Дополнение LFS-XXX · ГГГГ-ММ-ДД»). Принятое решение задним числом не переписывается.
- **Решение владельца в рамках одной задачи** (тексты, порядок, мелкое поведение) — раздел «Решения владельца»
  в `docs/tasks/LFS-XXX.md`.

- Итоговая навигация после появления Tasks — [PAGES.md](../reference/ui/PAGES.md#открытый-вопрос-итоговая-навигация), этап 9.

- Решения, которые ещё нужно зафиксировать по продукту, — Master Plan v0.4, §13.
