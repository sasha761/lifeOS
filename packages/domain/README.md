# @lifeos/domain

Будущие независимые бизнес-правила и интерфейсы всех сфер LifeOS.
В LFS-101 пакет экспортирует пустой TypeScript-модуль.

Пакет не импортирует Next.js, React или `apps/*` и не выполняет произвольные
запросы в обход репозиториев. Языковой модуль не определяет архитектуру ядра.

В LFS-108 включены настоящие `lint` (ESLint) и `typecheck` (strict tsc) в
общую проверку CI. Build/test заглушки удалены: бизнес-логики и отдельной
unit suite здесь пока нет. Контракты проверяются в `packages/contracts`.
Установка и проверки: [корневой README](../../README.md), [CI](../../docs/CI.md).
