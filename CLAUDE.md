## Claude Code

Правила выше написаны для Codex и без изменений действуют для Claude Code: где написано «Codex», читай «исполнитель».
Как Codex и Claude Code делят работу, описано в `docs/AI_AGENTS.md`.

- Отвечай владельцу по-русски.
- Задачу выполняй через `/lfs LFS-XXX`, проверку чужой работы делай через `/lfs-review LFS-XXX`.
- Перед изменением файлов покажи план и дождись подтверждения владельца (удобно в plan mode).
- Если в этой же папке сейчас работает Codex, не начинай правки, а спроси владельца.
- Код `apps/web`: Next.js 16, правила в `apps/web/AGENTS.md` (подключается через `apps/web/CLAUDE.md`). Перед кодом читай `apps/web/node_modules/next/dist/docs/`.
- Не читай и не выводи `.env`. Список переменных есть в `.env.example`.
- Не трогай и не приписывай себе незакоммиченные изменения других задач. `git commit` и `git push` делай только по прямой просьбе владельца.
- Проверки: `pnpm verify` и скрипты из `package.json`, порядок описан в `docs/DEVELOPMENT_WORKFLOW.md`. PostgreSQL для integration-тестов поднимается через `pnpm db:test:up` (Docker), Playwright-сценарии запускаются через `pnpm test:ui`.
- Картинки-референсы (например `docs/reference/ui/*.png`) открывай инструментом Read, ты их видишь.
- Скриншоты и прочие временные файлы клади в `.cache/` (он в `.gitignore`), а не в корень репозитория.
